# Codex Integration

Codex can use the package through the shell, without a vendor-specific connector.

```powershell
npm install
npm run check
npm run demo
```

Follow `AGENTS.md`. Use the JSON protocol for repeatable calls and keep personal data in ignored local files. Review every `requiresUserApproval` value before proposing an external action. See `docs/PLATFORM_GUIDES.md` for the complete workflow.
