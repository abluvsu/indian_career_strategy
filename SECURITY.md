# Security Policy

## Scope

This project handles career profiles and may later handle email metadata. Keep all personal data, OAuth tokens and generated documents local and private.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's private vulnerability reporting for this repository when available. If it is unavailable, open a minimal issue asking for a private contact channel without including exploit details or personal data.

## Supported versions

Only the latest release on the default branch is currently supported.

## User responsibility

Do not commit `.env` files, token files, databases, email exports, browser profiles or real candidate data. Review the staged file list before every push.
