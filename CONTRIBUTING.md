# Contributing

Contributions should improve reliability, privacy, explainability or user control.

Before opening a pull request:

1. Run `npm run check`.
2. Use fictional fixtures only.
3. Add tests for changed domain behavior.
4. Keep provider credentials and personal data out of commits.
5. Document new connectors, permissions and failure states.

External actions must remain behind explicit user approval. Do not add automatic email sending or application submission without a documented consent and safety review.
